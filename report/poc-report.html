⚙️ BasePage.ts — Core Abstraction

Every Page Object extends this class. Contains all navigation, wait, interaction, and assertion helpers — including auto language switching.

core/BasePage.ts 
export abstract class BasePage {
  protected page: Page;

  // Auto-switch to English if page loads in Arabic
  async goto(path: string = '/') {
    await this.page.goto(path);
    await this.waitForPageLoad();
    await this.switchToEnglishIfNeeded();
  }

  async switchToEnglishIfNeeded() {
    const engBtn = this.page.getByRole('button', { name: /^en$/i });
    try {
      await engBtn.waitFor({ state: 'visible', timeout: 3000 });
      await engBtn.click();
    } catch { /* already English */ }
  }

  // Smart fill — handles input[type=number] via JS evaluate
  async fillField(locator: Locator, value: string) {
    await this.waitForElement(locator);
    await locator.click();
    const inputType = await locator.evaluate((el: any) => el.type);
    if (inputType === 'number') {
      await locator.evaluate((el: any, val: string) => {
        el.value = val;
        el.dispatchEvent(new Event('input',  { bubbles: true }));
        el.dispatchEvent(new Event('change', { bubbles: true }));
      }, value);
    } else {
      await locator.clear();
      await locator.fill(value);
    }
  }
}

💡 Key Framework Decisions Made by Claude AI

Page Object Model (POM)

Each page gets its own class extending BasePage. Locators are declared as readonly properties, keeping tests clean and maintainable.

input[type=number] bypass

The Nafath ID field is type="number" — Playwright's fill() refuses non-numeric values. Claude solved this by detecting the input type and using JavaScript evaluate() to force values for negative test cases.

Auto Language Switch

The app defaults to Arabic on load. Claude added switchToEnglishIfNeeded() to BasePage.goto() — runs transparently on every navigation, clicking the EN button when present.

Environment Config

Centralised environments.ts with dev / staging / prod configs. ENV variable selects the target — default is UAT (uat-sp-frontoffice.sekaya.sa).

Separate story folders

Each Jira story gets its own folder under stories/ containing pages/, fixtures/, and specs/. Completely isolated — new stories never break existing ones.

🔧 Real Problems Claude Debugged & Fixed

Problem: Page loads in Arabic

Prompt: "here is one issue the tests are failing because when we open the tab by default the language is urdu you have to switch it to english and then run the tests. it button on top left as Eng click on it to switch to english"
Fix: Added switchToEnglishIfNeeded() to BasePage.goto() — automatically clicks EN button on every navigation.

Problem: Input field not found

Root cause: "Please enter ID Number" is display text above the field, not an HTML <label for="">. getByLabel() and getByPlaceholder() both failed.
Fix: Switched to page.locator('input').first()

Problem: Cannot type text into input[type=number]

Error: locator.fill: Error: Cannot type text into input[type=number] — Playwright refuses to put letters into number inputs.
Fix: Upgraded fillField() to detect type="number" and use el.evaluate() to bypass browser restriction — enables full negative testing.

Problem: Post-login assertion failed

Discovery: Screenshot showed the app skips Nafath verification entirely on UAT and redirects directly to the portal dashboard.
Fix: Changed happy path assertion from verificationNumber visible to assertURL(/^(?!.*\/login).*$/) — URL redirect is the correct success signal.

📋 GitHub Actions Workflow — playwright.yml
.github/workflows/playwright.yml 
name: Playwright Tests

on:
  push:
    branches: [main, master]
  pull_request:
    branches: [main, master]
  workflow_dispatch:
    inputs:
      story:
        description: 'Story folder (e.g. PROJ-43-login-nafath)'
      grep:
        description: 'Tag filter (e.g. @smoke)'

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        project: [chromium, firefox]   # parallel browsers

    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: npm ci
      - run: npx playwright install --with-deps ${{ matrix.project }}
      - run: npx playwright test --project=${{ matrix.project }}
        env: { ENV: staging }
      - uses: actions/upload-artifact@v4    # HTML report
        if: always()
        with: { path: playwright-report/ }
